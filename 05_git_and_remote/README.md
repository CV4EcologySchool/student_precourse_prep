# Session 5: Git and remote-computing basics

## What you should learn

- why Git tracks changes to code;
- the difference between Git and GitHub;
- the clone/pull/edit/add/commit/push cycle;
- the difference between your local computer and a remote computer;
- what SSH does and how to leave a remote session.

## Core Git exercise

Complete [`git_exercise.md`](git_exercise.md) using the repository or personal copy supplied by the instructors. It changes only `practice_note.md`; do not add research data.

## SSH

Read [`ssh_quickstart.md`](ssh_quickstart.md). If instructors have supplied real 2027 credentials, make one login, run `hostname` and `pwd`, and exit. Otherwise, reading the example and identifying which commands are local versus remote is enough.

- [Software Carpentry: Remotes in GitHub](https://swcarpentry.github.io/git-novice/07-github.html)

- [HPC Carpentry: Connecting to a remote HPC system](https://carpentries-incubator.github.io/hpc-intro/11-connecting.html)

These are references. Branching, conflicts, pull requests, job schedulers, and full remote-environment setup are not part of this exercise.
