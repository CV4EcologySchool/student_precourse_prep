# Randall fish teaching sample

This directory contains ten fish photographs and ten matching landmark
annotation files used in the CV4Ecology preparation exercises.

## Photographs

**Photographs by J.E. Randall, Bishop Museum, Honolulu.**

These photographs form part of the life's work of renowned ichthyologist J.E.
Randall and are provided here with the kind permission of the Bishop Museum for
research and educational use. They are third-party materials and are not
covered by any repository-wide software or content license. Contact the Bishop
Museum about uses outside research or education.

Collection: [John E. Randall's Fish Photos](http://pbs.bishopmuseum.org/images/JER/)

## Landmark annotations

Each CSV file contains landmarks for the JPG file with the same base name. The
annotations were created by the repository author as part of the research
project associated with this dataset. Their provenance and rights are separate
from those of the photographs. The annotation CSV files are copyright Tel Aviv
